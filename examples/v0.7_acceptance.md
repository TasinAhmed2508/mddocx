# Introduction {#sec-intro}

This release builds professional Word semantics on top of the existing compiler. A reviewer can leave a native annotation here{>>Confirm the final release number before publishing.<<} without changing the visible sentence.

> [!NOTE]
> This is a GitHub-style note callout. Its content remains editable Word text.

::: warning Compatibility boundary
The renderer uses safe, bounded parsers and never executes code blocks or arbitrary TeX.
:::
