# mddocx v1.0.0 validation report

## Release scope

v1.0.0 establishes the stable public API and production release gate. It keeps the v0.9 native Markdown → Word compiler surface while adding:

- public API version `1` and a machine-readable frozen manifest;
- advanced native ChartML controls: axis titles/ranges/number formats, data labels, legend placement, Office style IDs, gridline control, and secondary value axes for column/bar/line charts;
- structural DOCX accessibility auditing;
- deterministic large-document performance gating;
- stronger OOXML package validation for duplicate relationship/drawing/note IDs and chart/workbook relationships;
- cross-platform CI/release workflows and explicit compatibility/release documentation.

## Microsoft Word compatibility statement

The release uses native WordprocessingML, OMML and ChartML structures and includes stronger package validation. Automated visual QA here uses LibreOffice because Microsoft Word is not installed in this environment. Therefore this report does **not** claim that Microsoft Word 2019/2021/365 was executed in the sandbox. `docs/COMPATIBILITY_MATRIX.md` explicitly recommends a representative Microsoft Word smoke pass when a Word-equipped Windows/macOS environment is available.
