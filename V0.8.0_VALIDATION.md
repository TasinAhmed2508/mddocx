# mddocx v0.8.0 Validation Report

## Release scope

v0.8.0 implements Phase 7 project/build mode on top of the existing single-file Markdown → canonical AST → native DOCX compiler.

Validated additions:

- `mddocx.yml` project manifests;
- deterministic ordered source lists and source globs;
- secure nested `@include` resolution;
- inert scalar project variables;
- multi-file AST assembly with source-file metadata;
- chapter-relative image rebasing;
- dependency and include-cycle detection;
- incremental build-state fingerprints and output SHA-256 validation;
- portable watch mode;
- `mddocx build`, `mddocx watch`, `mddocx project init`, and `mddocx project info`;
- safe project-level render configuration;
- Word DATE-field compatibility correction found during rendered acceptance QA.

## Rendered-page QA

The acceptance DOCX was rendered through LibreOffice and `pdftoppm` at 120 DPI.

Result: 3 pages.

All three pages were visually inspected after the final source change. The pass verified:

- title page and date field;
- abstract/keywords;
- heading numbering;
- project-variable substitution;
- included callout content;
- chapter-relative image rendering;
- figure/listing captions;
- native OMML integral, radical, and matrix;
- cross-chapter references;
- native table layout;
- bibliography;
- Page X of Y footer fields.

During this pass, the pre-existing DATE field switch was found to be over-escaped. The field generator was corrected generically and a regression test was added. The regenerated title page no longer shows a trailing backslash after the date.

3. `mddocx build --force`;
4. generated-DOCX existence check;
5. `mddocx inspect --strict`.

Result: PASS.

The sandbox package index could not supply isolated build dependencies for the first `pip wheel` attempt (`setuptools>=68` was unavailable through that index). The wheel was therefore built with `--no-build-isolation` using the already installed setuptools 82.0.1 and wheel 0.46.3. This is an environment/package-index limitation, not a source or wheel failure.
