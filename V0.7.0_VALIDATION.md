# mddocx v0.7.0 Validation Report

## Release

- Version: `0.7.0`
- Milestone: Phase 6 — Word Professional Features
- Stable APIs preserved: `render()`, `render_string()`, `MarkdownWord`

## Implemented scope

- native multilevel Word heading numbering;
- section-scoped figure/table/listing captions and equation numbering;
- title pages, subtitles, organization, abstract and keywords;
- advanced first/even/odd header/footer handling;
- bounded native Word field templates and Page X of Y;
- GitHub-style and bounded container callouts;
- editable Pygments syntax highlighting, line numbers, highlighted lines and language labels;
- centralized Markdown attributes;
- native Word comments from CriticMarkup annotations;
- `mddocx template inspect`;
- stronger internal-reference/bookmark/comment integrity validation.

## Security checks

- Pygments tokenizes code but does not execute it.
- Field templates accept a fixed allowlist only.
- Callout containers accept a fixed semantic kind list only.
- Native Word comments contain inert text.
- Existing path traversal, resource/network, XML, compiler-limit, reproducibility and plugin boundaries remain active.

## Known limitations

- Heading numbering currently exposes decimal multilevel numbering only.
- Native comments are point annotations; Markdown syntax for ranged comments over arbitrary text spans is not yet implemented.
- Callouts are styled Word paragraphs, not floating text boxes.
- Final Word field refresh, font substitution, shaping and pagination remain host responsibilities.
