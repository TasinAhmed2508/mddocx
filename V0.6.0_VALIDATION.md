# mddocx v0.6.0 — Phase 5B Validation

## Release scope

Phase 5B adds professional Word-document semantics on top of the v0.5.0 fidelity/QA baseline:

- centralized semantic identifiers and Word-safe bookmark registry;
- native Word `SEQ` captions and `REF` cross-references;
- internal fragment hyperlinks;
- figure/table/listing captions and numbering;
- document-wide or H1-section-scoped equation numbering while retaining native editable OMML;
- native endnotes;
- citation AST, BibTeX/CSL-JSON input, deterministic APA/author-year/IEEE/numeric formatting, and bibliography generation;
- image alt/title/decorative metadata plus bounded percentage sizing/alignment;
- definition lists;
- safe offline Mermaid subsets for flowchart/graph, sequence, state, class, ER, mindmap, timeline, pie, journey, and gantt;
- extended DOCX inspection for publication/reference structures.

## Security verification

Phase 5B preserves prior trust boundaries:

- Markdown code blocks are never executed;
- TeX macros are not executed;
- Mermaid is parsed/rendered by bounded project-owned compatibility renderers, not Node/browser/shell/remote services;
- bibliography files are parsed as data only;
- remote resources remain opt-in and images-only;
- existing path, XML, compiler-limit, cache, and plugin restrictions remain in force.

## Intentional limitations

- Citation formatting is a deterministic project-owned subset, not full CSL style-language execution.
- Mermaid is a safe compatibility subset, not Mermaid JavaScript.
- SVG is rasterized for broad Word compatibility.
- Word/LibreOffice may need to refresh fields after editing/reordering content.
- Numbered equations use borderless one-row layout tables; generic accessibility tools can flag these as ordinary tables even though the semantic data tables are correctly marked with header rows.
- Native endnote hyperlink relationship handling is conservative; visible link text is retained.
