# mddocx v0.5.0 Validation

Date: 2026-08-08

## Release scope

v0.5.0 is the Phase 5A Word-fidelity and QA release. It is additive to the original
Phase 1–3 PRD and the v0.4.x operational/Word-compatibility work.

Implemented in this release:

- native Word `w14:checkbox` content controls for common Markdown task lists;
- `mddocx inspect` and programmatic DOCX inspection;
- `mddocx doctor` runtime/capability diagnostics;
- `mddocx visual-qa` plus reusable page-render comparison APIs;
- opt-in LibreOffice page-image regression fixture and baseline;
- deterministic 600-equation fallback-parser/OMML regression corpus;
- expanded common mathematical symbols/functions;
- stronger output validation for total package size, macros, duplicate package parts,
  internal relationships, and key OMML structural invariants.

workflow (LibreOffice -> PDF -> page PNGs). All 13 rendered pages were inspected.

## Math hardening corpus

A deterministic 600-expression corpus is converted through the project-owned safe
LaTeX-subset parser and MathML -> OMML renderer. The test covers powers, subscripts,
fractions/nested fractions, square/nth roots, integrals/contour integrals, sums,
products, limits, grouped superscripts, matrices, cases, aligned equations, accents,
math variants, boxes, Greek symbols, and common operators.

Checks include:

- every result is an `m:oMath` root;
- no generated text contains a placeholder square;
- every generated n-ary object has a concrete operand;
- no fallback-parser command token remains as a literal backslash command in the
  current corpus.

## Compatibility notes

- Checkbox content controls use Word 2010+ `w14:checkbox`; a Unicode checked/unchecked
  glyph is also embedded as a deterministic fallback for other OOXML hosts.
- Visual baselines are rendering-host/version-sensitive. Projects should establish
  baselines on the Word-compatible renderer used by their own CI.
- The internal LaTeX parser remains a safe deterministic subset rather than a TeX
  macro engine. `latex2mathml` remains optional.
- Mermaid remains an offline bounded compatibility subset.
