# mddocx v0.9.0 Validation Report

## Release scope

v0.9.0 is the Phase 8 release for native editable Office charts and structured CSV/JSON data imports. The established Markdown → canonical AST → normalization → DOCX renderer architecture remains unchanged; chart/data support is added as semantic AST nodes and dedicated OOXML/data subsystems.

Implemented in this release:

- native Office ChartML for column, bar, line, pie, and scatter charts;
- one deterministic embedded `.xlsx` workbook per chart so chart data remains editable in Word;
- inline chart data and local CSV/JSON-backed charts;
- CSV/JSON imports as native Word tables;
- chart/table captions, bookmarks, SEQ numbering, and REF cross-references;
- project-relative data rebasing, root confinement, dependency fingerprinting, and watch/incremental rebuild integration;
- bounded row/column/series/point limits and structured DATA/CHART diagnostics;
- `mddocx data inspect` and native chart/workbook reporting in `mddocx inspect`;
- corrected first-object chapter sequence reset behavior for Word/LibreOffice section-scoped numbering.

## Known bounded scope

- Stable chart types are column, bar, line, pie, and scatter.
- Advanced chart features such as combo charts, secondary axes, trendlines, error bars, custom axis scales, and rich legend/data-label configuration are deferred to v1.0+ hardening.
- Structured data imports are intentionally local CSV/JSON only and never execute formulas, database queries, Python, shell commands, or arbitrary transformation expressions.
- Final field refresh, font substitution, and pagination remain host-application responsibilities.

## Release decision

**PASS — v0.9.0 is suitable for release as the native chart / structured data milestone.**
